Sl.No Block Level
Elements		 Description
(A block-level element always takes up the full width available)
1 div Defines a division or a section in an HTML document
2 h1-h6 Defines HTML headings (h1 is the largest, h6 is the smallest)
3 p Defines a paragraph
4 form Defines an HTML form for user input
5 header Defines a header for a document or section
6 footer Defines a footer for a document or section
7 section Defines a section in a document
8 article Defines an article
9 nav Defines navigation links
10 aside Defines content aside from the page content
11 dd Defines a description in a description list
12 dt Defines a term in a description list
13 li Defines a list item
14 ol Defines an ordered list
15 ul Defines an unordered list
16 table Defines a table


Sl.No Inline Level
Elements		 Description
(An inline element does not start on a new line and only takes up
as much width as necessary)
1 span Defines a section in a document (used for styling purposes)
2 a Defines a hyperlink
3 img Defines an image
4 b Defines bold text
5 i Defines italic text
6 u Defines underlined text
7 strong Defines important text (usually displayed in bold)
8 em Defines emphasized text (usually displayed in italics)
9 button Defines a clickable button
10 input Defines an input field where the user can enter data
11 label Defines a label for an input element
12 select Defines a drop-down list
13 textarea Defines a multi-line text input control
14 small Defines smaller text
15 sub Defines subscripted text
16 sup Defines superscripted text
